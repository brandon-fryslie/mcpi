### Enable/Disable File Pattern

**Active File** (ENABLED servers):
```
~/.codeium/windsurf/mcp_config.json
```

**Disabled File** (DISABLED servers):
```
~/.codeium/windsurf/mcp_config_disabled.json
```

**Behavior**:
- `disable`: MOVE server config from active → disabled file
- `enable`: MOVE server config from disabled → active file
- State persists across plugin restarts (filesystem-based)
