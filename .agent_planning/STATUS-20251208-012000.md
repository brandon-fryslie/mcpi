## Context: What Feature Is Being Tested?

The tests in `test_cli_add_discover.py` validate a **proposed feature** that would add text-search discovery to the `mcpi add` command.

### Current State vs Desired State

**CURRENT BEHAVIOR** (`mcpi add`):
1. User runs `mcpi add <server_id>`
2. System looks up `<server_id>` in catalog
3. If found: installs server
4. If NOT found: shows "Server not found in catalog" error

**DESIRED BEHAVIOR** (discovery mode):
1. User runs `mcpi add <arbitrary_text>`
2. System checks if `<arbitrary_text>` is in catalog
3. If NOT found: **enters discovery mode**
   - Calls Claude CLI with the text
   - Claude discovers server details
   - System installs discovered server directly
4. If found: uses normal catalog flow (backward compatible)

### What Already Exists

There IS a `mcpi catalog add` command that uses Claude CLI for discovery:
- File: `src/mcpi/cli.py`, lines 2314-2450+
- Command: `mcpi catalog add <url/text>`
- Uses Claude CLI to discover server info
- Adds discovered server to LOCAL CATALOG
- **This is a 2-step flow**: catalog add → then mcpi add

The proposed feature would make it 1-step: `mcpi add <url/text>` directly.
