Implementation Summary:
======================
Successfully implemented discovery mode for the `mcpi add` command. When a user provides
arbitrary text (URL, package name, etc.) that is not found in the catalog, the system
now automatically enters discovery mode and uses Claude CLI to discover server information
and install it directly.

Key Features Implemented:
-------------------------
1. Discovery Mode Detection
   - Detects when server_id is not in catalog
   - Automatically enters discovery mode with user-friendly message
   - Falls back to catalog mode for known servers (backward compatible)

2. Claude CLI Integration  
   - Calls Claude CLI with --print flag for non-interactive discovery
   - Sends structured prompt requesting JSON response
   - Handles version check, timeouts, and errors gracefully

3. Response Parsing
   - Parses JSON response from Claude containing server config
   - Extracts: id, description, command, args, env, repository
   - Validates required fields and handles malformed responses
   - Strips markdown code blocks if present

4. Installation
   - Creates ServerConfig from discovered information
   - Uses discovered server_id (allows Claude to normalize names)
   - Integrates with existing --client, --scope, --dry-run options
   - Shows discovered info to user before installation

5. Error Handling
   - Claude CLI not found → helpful error with install link
   - Claude timeout → clear timeout message
   - Parse errors → helpful debugging info in verbose mode
   - Returns exit code 1 on discovery failure
